# Panel-extract sources（git 外）

出版論文 PDF / 投稿前 Word / `legend_excerpt.txt` をここに置く。

```
input/panel_extract/
  paper_01/   # PDF or .docx (+ optional legend_excerpt.txt)
  paper_02/
  paper_XX/   # copy from fixtures/gold/panel_extract/_template
```

Gold 雛形・人手手順は `fixtures/gold/panel_extract/`（追跡）。  
このディレクトリの PDF・docx・filled テキストは **コミットしない**。
