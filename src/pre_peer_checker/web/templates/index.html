            抽象ルールの標準 JSON だけを共有します（PDF・コメント全文・著者名・DOI は載せません）。 トークン入力は不要です。Issue は GitHub の下書きページを開き、PR は CLI をコピーします。 絶対ルール: 表現を取らない／検査仕様に抽象化／コメント者を名指し・攻撃しない。
